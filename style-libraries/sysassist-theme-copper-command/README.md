# SysAssist Theme: Copper Command

Warm copper/gold command-center theme with amber confidence charts and strong alert readability.

## Install

Copy or link this folder as a local package:

```ts
import '@sysassist/theme-copper-command/theme.css'
import copperCommandStyleLibrary, { dashboardPreset } from '@sysassist/theme-copper-command'
```

The package includes `manifest.json` for catalog import, but normal code import does not require writing JSON by hand.

## Dashboard Additions

The preset recommends an approval pressure bar chart, a remediation funnel, and a risk heat strip.
