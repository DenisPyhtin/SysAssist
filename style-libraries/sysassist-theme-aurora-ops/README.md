# SysAssist Theme: Aurora Ops

Cool green/cyan operational theme with calm contrast and soft monitoring charts.

## Install

Copy or link this folder as a local package:

```ts
import '@sysassist/theme-aurora-ops/theme.css'
import auroraOpsStyleLibrary, { dashboardPreset } from '@sysassist/theme-aurora-ops'
```

The package includes `manifest.json` for catalog import, but normal code import does not require writing JSON by hand.

## Dashboard Additions

The preset suggests a service temperature area chart, an uptime sparkline, and a capacity ribbon using the palette in `theme.css`.
