# SysAssist Theme: Midnight Grid

High-focus midnight theme with blue steel panels, crisp contrast, and dense infrastructure graphs.

## Install

Copy or link this folder as a local package:

```ts
import '@sysassist/theme-midnight-grid/theme.css'
import midnightGridStyleLibrary, { dashboardPreset } from '@sysassist/theme-midnight-grid'
```

The package includes `manifest.json` for catalog import, but normal code import does not require writing JSON by hand.

## Dashboard Additions

The preset suggests module dependency graph, incident waterfall, and correlation density charts.
